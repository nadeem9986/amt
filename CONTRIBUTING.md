# Contributing Guidelines for Amanat Transport

Thank you for your interest in contributing to the **Amanat Transport** open-source web platform! We welcome pull requests, feature suggestions, and bug reports.

---

## 🚀 How to Contribute

1. **Fork the Repository**:
   Create a personal fork of `https://github.com/nadeem9986/amt.git` on GitHub.

2. **Clone your Fork**:
   ```bash
   git clone https://github.com/YOUR-USERNAME/amt.git
   cd amt
   ```

3. **Create a Feature Branch**:
   ```bash
   git checkout -b feat/your-feature-name
   ```

4. **Code Standards**:
   - Maintain the single-file bundling model in `index.html` unless adding distinct external documentation or media assets.
   - Use semantic commit messages (`feat`, `fix`, `style`, `perf`, `docs`).
   - Ensure responsive layout compatibility across desktop, tablet, and mobile breakpoints.

5. **Submit a Pull Request**:
   Push your branch and open a Pull Request against `origin/main` with a clear description of your changes.
